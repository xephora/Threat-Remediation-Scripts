### Actions
- Terminates processes associated with Pulse Browser unwanted software
- Remove Pulse Browser unwanted software from the file system.
- Remove Pulse Browser unwanted software registry keys.
- Performs checks to ensure removal was completed and lets you know if it wasn't successful.

### Description
A remediation script was created for Pulse Browser thanks to @malo-fevin for reporting the issue https://github.com/xephora/Threat-Remediation-Scripts/issues/23. The script is intended for CrowdStrike but can be run without it.
