# blazer browser Remediation script

### Actions
- Terminates processes associated with blazer browser unwanted software
- Remove blazer browser unwanted software from the file system.
- Remove blazer browser unwanted software registry keys.
- Remove blazer browser uninstall key.
- Performs checks to ensure removal was completed and lets you know if it wasn't successful.

Thank you, @chan-man, for opening an issue and submitting this script for consideration. https://github.com/xephora/Threat-Remediation-Scripts/issues/21
