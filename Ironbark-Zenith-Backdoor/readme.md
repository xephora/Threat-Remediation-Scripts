# Ironbark (Zenith Backdoor) Remediation script

### Actions
- Terminates processes associated with Ironbark unwanted software
- Remove Ironbark unwanted software from the file system.
- Remove Ironbark unwanted software registry keys.
- Performs checks to ensure removal was completed and lets you know if it wasn't successful.

### Description
I have created an automated script to remove Zenith Backdoor. The script is intended for CrowdStrike but can be run without it.
